# Wonderline

Keep talking while your imagination takes shape, stroke by stroke.

[Open the studio](https://ashstarry.github.io/wonderline/) · [Original studio](https://softspoken-paper-garden.neonolm3.chatgpt.site/)

This repository contains the browser-only release for GitHub Pages. Speech recognition and drawing generation run in the existing cloud service. No personal computer serves this website. No API keys, server secrets, recordings, drawing histories or transcripts are included in this repository.

Your drawings and words are stored in your browser on each site's origin; the two addresses do not share that local history.
